# 😷 Face Mask Detection using Deep Learning

## 📌 Project Overview
A Computer Vision project that detects whether a person 
is wearing a face mask or not using Transfer Learning 
with MobileNetV2.

- TensorFlow / Keras
- OpenCV
- MobileNetV2 (Transfer Learning)
- Google Colab
- scikit-learn

## 📁 Project Structure
face-mask-detection/
│
├── face_mask_detection.ipynb   # Main notebook
└── README.md                   # Project description

## 🚀 How to Run
1. Open the notebook in Google Colab
2. Run all cells from top to bottom
3. Model trains in ~10 minutes

## 📊 Model Architecture
- Base: MobileNetV2 (pretrained on ImageNet)
- Added: GlobalAveragePooling2D + Dense + Dropout
- Output: 2 classes (Mask / No Mask)
